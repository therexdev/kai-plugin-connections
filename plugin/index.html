Credentials stay with you

Core encrypts credentials using your operating system's secure storage. This plugin receives account metadata and selected action responses.

KAI-managed connections require account sign-in and a server configured for Composio. Your own project works with a Composio API key. Local-Only blocks account API requests.

Connecting an account does not grant it to rented agents or publish it to the Agent Network.

Connect an app

  2. Choose the account and permissions to share.
  3. Return to Connected, refresh, and choose what KAI can use.
